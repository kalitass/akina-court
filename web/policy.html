The rules the court applies

Ryde Dispute Resolution Policy — Akina Court edition: 31 numbered clauses in 8 groups, built on Ryde's official Dispute Resolution Policy v2.1. 25 come from the official documents and 6 are system rules. The official documents take priority; where they are silent, this system sets the rule. Every ruling names the clauses it applies, and each clause ends with the document it comes from.

  • Official stated in an official document.
  • Official + system detail the rule is official; how this system applies it to the records is ours or from a Ryde help-centre page.
  • System rule not in the official documents; quoted from a Ryde help-centre page where one states it.
  • Set by this system in a source line: neither the official documents nor Ryde's public pages specify it.

0. Fare

  1. FARE-0 Fare build-upOfficial + system detail

    Actual fare = (base + distance + time fare) × surge multiplier at trip start + booking fee (not surged) + tolls / ERP (at cost) + published add-on fees. All service types.

    Source Ryde Dispute Resolution Policy v2.1 Appendix A, §3.5 · DISP-001 sample case · Ryde Help Centre: edit destination fee
    Source wording

    Ryde Dispute Resolution Policy v2.1 Appendix A "calculated using actual distance, actual time, and the surge multiplier in effect at trip start"; Ryde Dispute Resolution Policy v2.1 §3.5 "Booking fee" surge-exempt; DISP-001 sample case "Tolls are passed through at cost." Add-on fees: Ryde Help Centre: edit destination fee "a $3.00 add/edit destination fee will apply".

1. Route deviation

  1. RD-1 Distance and toleranceOfficial + system detail

    Deviation = actual distance − recommended distance. ≤ 1 km → no refund.

    Source Ryde Dispute Resolution Policy v2.1 §1.4, §1.3
    Source wording

    Ryde Dispute Resolution Policy v2.1 §1.4 "actual_route_distance − recommended_route_distance"; §1.3 "deviation ≤ 1km … No refund (within tolerance)".

  2. RD-2 Refund matrixOfficial + system detail

    Deviation over 1 km:

    SituationOutcome
    Traffic reason, rider informed and agreedno action
    Traffic reason, rider not informedRefund excess distance fare, partial refund
    No traffic reasonRefund excess distance fare, partial refund; record a driver violation

    Amount = refundable km × this trip's per-km distance fare (or excess_distance_fare if given). Tolls, time fare and surge are not refunded.

    Source Ryde Dispute Resolution Policy v2.1 §1.3 · DISP-001 sample case
    Source wording

    Ryde Dispute Resolution Policy v2.1 §1.3 "rider informed and agrees … No refund", "rider not informed … Partial refund of excess distance fare", "without traffic justification … Full refund of excess distance fare"; DISP-001 sample case "calculated at $0.80/km … $3.44", "Only the excess distance fare is refunded." Exempt km: set by this system.

  3. RD-3 Rider-requested stops or routesSystem rule

    Rider named a place or route in chat and the driver accepted, or an in-app destination change / added stop was accepted → that segment is not a deviation. Driver chose an off-route place the rider did not name, without saying so beforehand → not exempt. Stop time is charged as time fare. An accepted destination change adds $3.00.

    Source Ryde Help Centre: preferred route · Ryde Help Centre: edit destination fee · Set by this system: driver-chosen places, stop time
    Source wording

    Ryde Help Centre: preferred route "reach a mutual agreement before you go"; Ryde Help Centre: edit destination fee "If the driver accepts your edit destination request, a $3.00 … fee will apply". Driver-chosen places, stop time: set by this system.

  4. RD-4 Traffic reasonOfficial + system detail

    A reroute needs traffic data showing closure, incident or congestion on the replaced part of the recommended route at trip time.

    Source Ryde Dispute Resolution Policy v2.1 §1.1, §1.4 · LTA DataMall: traffic speed bands
    Source wording

    Ryde Dispute Resolution Policy v2.1 §1.1 "in response to real-time traffic conditions, road closures, or congestion"; §1.4 "verified via historical traffic API data for the route segment"; LTA DataMall: traffic speed bands "1 – indicates speed range from 0 < 9 2 – … 10 < 19".

  5. RD-5 Notice and consentOfficial + system detail!Why we chose thisRyde's policy says a detour without a traffic reason is refunded, even if the rider was told about it. It also says a detour the rider agreed to counts as agreed. We read both together: just telling the rider is not enough, but if the rider clearly said yes before the detour, it was the rider's own choice, so there is no refund.

    The driver must tell the rider before or at the point of deviation, by in-app chat or phone; a brief reason is enough. Chat or call recording shows the rider acknowledged → agreed.

    Source Ryde Dispute Resolution Policy v2.1 §1.2, §1.4 · Ryde Help Centre: preferred route
    Source wording

    Ryde Dispute Resolution Policy v2.1 §1.2 "MUST inform the rider … via in-app chat or verbally (with the trip call recording as evidence) before or at the point of deviation"; §1.4 "call recording confirms rider acknowledgment, the deviation is considered agreed"; Ryde Help Centre: preferred route "reach a mutual agreement before you go".

  6. RD-6 Repeat deviationsSystem rule

    Upheld against the driver, and the driver had an upheld deviation in the last 90 days → add account review flag. The profile never decides the current case.

    Source Ryde Help Centre: driver standards · Set by this system: 90 days
    Source wording

    Ryde Help Centre: driver standards "Repeated or severe breaches may lead to permanent suspension". 90 days: set by this system.

  7. RD-7 Reminder after uninformed rerouteOfficial

    Refund for not informing the rider → also send the driver a notification-duty reminder and log it on the driver's route compliance record; no formal warning for a first such incident.

    Source DISP-001 sample case
    Source wording

    DISP-001 sample case actions "Issue a reminder to the driver … No formal warning given as this is a first notification-related incident", "Log the notification failure".

2. No-show and cancellation

  1. NS-0 Which clauseSystem rule

    Driver cancelled for rider no-show → NS-1 / NS-2; driver cancelled for another reason → NS-3; rider cancelled → NS-4; driver did not arrive → NS-8.

    Source Set by this system

  2. NS-1 No-show fee standsOfficial + system detail!Why we chose thisRyde's policy counts the 5-minute free wait from the scheduled pickup time, but its own example case (DISP-002) counts from when the driver arrived and uses an 8-minute limit written in the trip record. We do both: the 5 minutes count from whichever is later, arrival or the scheduled time; a limit written in the trip record counts from arrival, as the example does.

    Driver cancels for rider no-show: the $5.00 fee stands (paid to the driver) only if all hold:

    (i) driver arrived: pressed "I'm Here" or arrival was auto-confirmed, with GPS within 200 m of the pickup point;

    (ii) the 5-minute free wait passed, counted from the later of scheduled pickup time and arrival; a no-show threshold in the record (DISP-002: 8 min) applies instead;

    (iii) before cancelling, the driver sent ≥ 1 in-app message and made ≥ 1 in-app call;

    (iv) the driver stayed at the pickup point throughout; a GPS gap that leaves this unproven → escalate.

    Source Ryde Dispute Resolution Policy v2.1 §2.1, §2.2, §2.3 · Ryde Help Centre: driver marked arrival · DISP-002 sample case
    Source wording

    Ryde Dispute Resolution Policy v2.1 §2.1 "free wait time of 5 minutes from the scheduled pickup time"; §2.2 "$5.00 … transferred to the driver"; §2.3 "At least 1 in-app chat message, AND … At least 1 phone call"; Ryde Help Centre: driver marked arrival "at the pick-up location according to GPS data"; DISP-002 sample case "Auto-arrival confirmed", "no_show_threshold_min": 8.

  3. NS-2 No-show fee voidedOfficial + system detail

    Any NS-1 condition fails → full refund of $5.00. Driver marked arrival while GPS was not at the pickup point → also account review flag.

    Source Ryde Dispute Resolution Policy v2.1 §2.3 · Ryde Help Centre: driver standards
    Source wording

    Ryde Dispute Resolution Policy v2.1 §2.3 "the cancellation fee is voided and the rider is not charged"; Ryde Help Centre: driver standards "Fraudulent behavior … 8. Abuse of Cancellation and Waiting Fee Policy".

  4. NS-3 Driver cancelled for another reasonSystem rule

    → No fee; if charged, full refund.

    Source Ryde Help Centre: cancellation and waiting fee
    Source wording

    Ryde Help Centre: cancellation and waiting fee lists the only chargeable cases: "Rider cancels after 3 minutes of matching OR The driver presses "I'm Here", waits … and cancels the trip (Rider NO SHOW …)".

  5. NS-4 Rider cancelledSystem rule

    Within 3 minutes of matching → free; later → $5.00 fee (Ryde's help centre says $6.61; this system uses the official $5.00).

    Source Ryde Help Centre: cancellation and waiting fee · Ryde Dispute Resolution Policy v2.1 §2.2
    Source wording

    Ryde Help Centre: cancellation and waiting fee "within 3 minutes of matching are not chargeable"; Ryde Dispute Resolution Policy v2.1 §2.2 "cancellation fee of $5.00".

  6. NS-8 Driver did not arriveOfficial

    Driver not at pickup by scheduled time + 5 min → rider may cancel free; a fee charged → full refund. Driver also made no contact attempt → add $5.00 goodwill credit.

    Source Ryde Dispute Resolution Policy v2.1 §2.4
    Source wording

    Ryde Dispute Resolution Policy v2.1 §2.4 "scheduled pickup time + 5 minutes), the rider may cancel at no charge", "fails to attempt contact … $5.00 goodwill credit".

  7. NS-9 Repeat rider no-showsOfficial!Why we chose thisRyde's policy flags a rider with 3 or more no-shows in 30 days. We add one limit: the history can flag the account for review, but it never decides who is right in this dispute. That rests only on this trip's records.

    ≥ 3 no-show cancellations in a rolling 30 days → account review flag (upfront payment; suspension pending Trust & Safety review). The profile never decides the current case.

    Source Ryde Dispute Resolution Policy v2.1 §2.5
    Source wording

    Ryde Dispute Resolution Policy v2.1 §2.5 "3 or more no-show cancellations within a 30-day rolling window … flagged".

3. Surge pricing

  1. SURGE-1 Quote lock and noticeOfficial!Why we chose thisRyde's policy lists three things a surge notice must say: the new multiplier, the new estimated fare, and that the rider can cancel for free. It does not say what happens if one is missing. We count a notice that leaves any of them out as no notice, because the rider could not make a real choice without all three.

    The quote is binding at the multiplier when quoted. Multiplier rises before trip start → in-app notice before or at pickup stating the new multiplier, the revised estimated fare, and free cancellation. Missing any item → not notified.

    Source Ryde Dispute Resolution Policy v2.1 §3.1, §3.2
    Source wording

    Ryde Dispute Resolution Policy v2.1 §3.1 "binding at the surge multiplier in effect at quote time"; §3.2 "new surge multiplier … revised estimated fare … option to cancel without penalty".

  2. SURGE-2 Surge refundOfficial

    SituationOutcome
    Surge rose, rider notified, rodeno action
    Surge rose, rider not notifiedRefund full surge differential, partial refund
    Surge fellLower fare applies
    UnchangedQuoted fare applies
    Source Ryde Dispute Resolution Policy v2.1 §3.3 · DISP-003 sample case
    Source wording

    Ryde Dispute Resolution Policy v2.1 §3.3 "rider not notified … Full refund of the surge differential"; DISP-003 sample case "rider_notified": false.

  3. SURGE-3 DifferentialOfficial + system detail

    Differential = actual fare − quote, when the whole difference comes from surge.

    Source Ryde Dispute Resolution Policy v2.1 §3.4 · DISP-003 sample case
    Source wording

    Ryde Dispute Resolution Policy v2.1 §3.4 "actual_fare − upfront_quote … attributable solely to a surge multiplier change"; DISP-003 sample case "surgeable_subtotal": 9.00.

4. Vehicle damage

  1. DMG-1 ClaimsOfficial

    Driver may claim cleaning or repair for rider-caused damage: spills, vomit, stains; interior damage (seats, doors, windows); exterior damage while boarding or alighting.

    Source Ryde Dispute Resolution Policy v2.1 §4.1
    Source wording

    Ryde Dispute Resolution Policy v2.1 §4.1 "cleaning or repair fees resulting from rider-caused damage".

  2. DMG-2 EvidenceOfficial

    Photos within 24 hours of trip end, taken and auto-timestamped in the Ryde driver app (no external uploads), linked to the trip by GPS and trip time.

    Source Ryde Dispute Resolution Policy v2.1 §4.2
    Source wording

    Ryde Dispute Resolution Policy v2.1 §4.2 "within 24 hours", "built-in camera, not external uploads", "via GPS telemetry and trip timestamp".

  3. DMG-3 AmountsOfficial

    Cleaning up to $50.00 on photos alone. Repair at cost, with a certified workshop's written quote within 7 days.

    Source Ryde Dispute Resolution Policy v2.1 §4.3
    Source wording

    Ryde Dispute Resolution Policy v2.1 §4.3 "Up to $50.00", "written quote from a certified workshop; quote must be submitted within 7 days".

  4. DMG-4 Insufficient evidenceOfficial!Why we chose thisRyde's policy says a rider who disputes a damage claim goes to a person (§4.4), but it also lets the system decide a cleaning fee up to $50 when the photos can be checked (§6.2). We follow the more specific rule: a cleaning fee up to $50 with checkable photos is decided by the system; anything else goes to a person (see C2 below).

    No timestamp, external photo, or not linked to the trip → claim rejected, fee waived. Rider disputes the damage → see TH-2.

    Source Ryde Dispute Resolution Policy v2.1 §4.4
    Source wording

    Ryde Dispute Resolution Policy v2.1 §4.4 "If evidence is insufficient … the claim is rejected".

5. Safety

  1. SAFE-1 Safety screenOfficial + system detail

    Any case, whatever type was filed: chat, complaint or appeal describes dangerous driving, harassment, assault or threats, inappropriate conduct, an accident, or someone feeling unsafe → escalate to a person.

    Source Ryde Dispute Resolution Policy v2.1 §5.2
    Source wording

    Ryde Dispute Resolution Policy v2.1 §5.2 "flag any dispute that contains safety-related keywords or indicators for immediate human escalation, regardless of the dispute type".

  2. SAFE-2 Accident and injuryOfficial + system detail

    Accident, injury or dangerous driving → escalate to a person; the summary lists 995, the driver's commercial motor insurance and RydeHELP.

    Source Ryde Dispute Resolution Policy v2.1 §5.1 · Ryde Help Centre: safety and accidents
    Source wording

    Ryde Dispute Resolution Policy v2.1 §5.1 "Traffic accidents during the trip"; Ryde Help Centre: safety and accidents "call 995 … driver's commercial motor insurance … via RydeHELP".

  3. SAFE-3 AI limits in safety casesOfficial

    The AI may only gather evidence, summarise accounts and prepare the case file; it may not rule, assign fault or recommend an outcome.

    Source Ryde Dispute Resolution Policy v2.1 §5.2
    Source wording

    Ryde Dispute Resolution Policy v2.1 §5.2 "CANNOT issue rulings, determine fault, or recommend resolutions on safety incidents".

  4. SAFE-4 Interim measuresOfficial

    After escalation the system may suspend the accused party (no trip acceptance / no booking) until human review; lifted if no violation is found. Action interim suspension.

    Source Ryde Dispute Resolution Policy v2.1 §5.3
    Source wording

    Ryde Dispute Resolution Policy v2.1 §5.3 "Temporary suspension of the accused party's account", "lifted if the human reviewer determines no safety violation occurred".

6. System decision or human review

  1. TH-1 By amountOfficial

    AmountPath
    Under $10System ruling final
    $10–$50System rules at confidence ≥ 80%, else escalate
    Over $50Human review; system prepares the case file
    Source Ryde Dispute Resolution Policy v2.1 §6.1
    Source wording

    Ryde Dispute Resolution Policy v2.1 §6.1 table.

  2. TH-2 By categoryOfficial!Why we chose thisRyde's policy says detours over 2 km go to a person. But Ryde's own example case (DISP-001) had a 4.3 km detour and settled it automatically with a $3.44 refund. We follow the example: refunds under $10 are settled by the system.

    Safety → human. No-show / cancellation → system final ($5.00 fixed). Fare → TH-1. Route deviation → by amount as TH-1, following DISP-001 (section 9, C1). Damage → cleaning ≤ $50 with verifiable photos: system; repair over $50: human.

    Source Ryde Dispute Resolution Policy v2.1 §6.2 · DISP-001 sample case
    Source wording

    Ryde Dispute Resolution Policy v2.1 §6.2 table; DISP-001 sample case "assigned_to": "RydeResolve_Auto_Resolution".

  3. TH-3 ConfidenceOfficial + system detail

    Based on evidence completeness, policy clarity, precedent alignment, party credibility. Any party with fraud flag ≥ 1 → threshold 95%, any amount.

    Source Ryde Dispute Resolution Policy v2.1 §6.3
    Source wording

    Ryde Dispute Resolution Policy v2.1 §6.3 "evidence completeness, policy clarity, precedent alignment, and party credibility", "fraud flag ≥ 1 … raised to 95%".

  4. TH-4 Missing recordsSystem rule

    A missing or broken GPS track, untimestamped messages, no record of who cancelled, etc. leaves an outcome-relevant condition undecidable → escalate, stating what is missing. Missing records favour neither party.

    Source Set by this system

    Source wording
