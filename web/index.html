Akina Court is a multi-agent court for ride-hailing disputes: route deviation, no-show fees, surge pricing, safety. Today a support agent settles each one by hand.

A ride dispute settled in 30 seconds, every ruling on the record.

The rider gets an AI advocate; the driver gets one too. Each argues its side, but only from facts that code computed first: the GPS track against the best route, every message, every fare line. An AI judge rules on what the policy leaves open. Before anything happens, code checks every citation, the allowed outcome and the amount against a public, numbered policy. A refund that passes is approved to go back to the rider's original payment method; safety cases, account actions and any failed check go to a person with the file ready.

How a case is decided

Code holds the model to the record. The model reads only numbered facts, may cite only facts and clauses that exist, and decides only what the policy leaves open. Code checks every output before anything happens.

The harness: what code fixes before, between and after every model callCode steps give the same output for the same input. Model steps are held to a contract that the next code step checks.
  1. 1 · Code

    Facts

    Code reads trip records, GPS, chat, calls, traffic and weather and writes numbered facts.

    The model never sees the raw record and never measures anything itself.

    C-0001: 20 facts, F1–F20
  2. 2 · Code

    Policy engine

    31 sourced clauses run as code and issue a certificate: allowed outcomes, the formula, the questions left open.

    The model can’t choose an outcome the policy rules out.

    C-0001: 6 elements left to the judge, the rate per km fixed
  3. 3 · LLM

    Two advocates

    Each argues once and rebuts once, for one side, through logged read-only tools.

    Advocates can cite evidence; they can’t add any.

    C-0001: 9 + 7 claims, 8 + 9 rebuttal points
  4. 4 · Code

    Citation check

    Every cited fact id and clause id is looked up.

    A claim citing something unknown or unread is struck in public.

    50 runs: 7 claims struck in 5 cases
  5. 5 · LLM

    Judge

    Rules only on the questions the certificate leaves open and returns structured fields.

    The judge applies the policy; it doesn’t write it.

    C-0001: detour 1 on the road the rider named; detour 2 counts
  6. 6 · Code

    Policy check

    Outcome in the allowed set, amount equal to the formula to the cent, an account flag only as a structured field.

    A failed check goes back to the judge once; if it still fails, a person decides.

    50 runs: 4 sent back once, all 4 corrected
  7. 7 · Code

    Notices

    Rider and driver notices are built from the final structured ruling.

    A notice can’t promise money the ruling doesn’t give.

    50 runs: model text replaced in 8 cases

How to read it

  • Clean facts alone barely help: 21 → 24 when the same model receives code-computed facts instead of the raw record; the mistakes are in applying the policy.
  • The code check blocks wrong executions: 29 and 26 wrong decisions acted without it; with it, the judge and the full court let 6 and 0 of 50 through.
  • The advocates close the gap the judge alone leaves: judge + check leaves 6 wrong decisions executed (44/50 right or handed to a person); the full court leaves 0 (50/50): both sides' reasoning on the record, a policy ground each side states for every open segment, and a second look whenever the judge departs from a reading both sides share.

"Match" means agreement with the policy-derived reference: a policy-conformance measure, not production accuracy. Model, run window, token counts and how to recompute every number: method and data · per-case tables and confusion matrices: full results.
